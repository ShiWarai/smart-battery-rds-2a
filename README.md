## 📋 Описание проекта 📋

Проект "smart-battery-esp32c3" представляет собой прошивку для микроконтроллера внутри умного аккумуляторного блока робота RDS-2A. Прошивка обеспечивает мониторинг и управление параметрами аккумулятора через USB и беспроводные интерфейсы.

## 🛠️ Комплектующие 🛠️

Для сборки и эксплуатации проекта вам понадобятся следующие компоненты:
- **Микроконтроллер Seeed studio ESP32C3**
- **OLED дисплей (64x32)**
  - VCC -> 3.3V
  - GND -> GND
  - SCL -> GPIO5
  - SDA -> GPIO4
- **Датчик тока и напряжения INA226**
  - VCC -> 3.3V
  - GND -> GND
  - SCL -> GPIO5
  - SDA -> GPIO4
- **Бузер**
  - Положительный вывод -> GPIO10
  - Отрицательный вывод -> GND
- **Кнопка**
  - Один вывод -> GPIO2
  - Другой вывод -> GND
- **Соединительные провода и разъемы**

## 💻 Установка и прошивка модуля 💻

### 🛠️ Установка PlatformIO 🛠️

1. Установите [Visual Studio Code](https://code.visualstudio.com/).
2. Установите расширение [PlatformIO](https://platformio.org/install/ide?install=vscode).

### ⚙️ Настройка проекта ⚙️

1. Клонируйте репозиторий проекта на ваш компьютер.
2. Откройте проект в Visual Studio Code.
3. Убедитесь, что файл platformio.ini настроен правильно. В нем должны быть указаны необходимые библиотеки и параметры сборки.
4. В корне проекта создайте новый файл с именем secret_values.ini и добавьте следующую секцию и параметры:
    ```ini
    [secrets]
    build_flags = 
        '-D WIFI_SSID="your_wifi_ssid"'
        '-D WIFI_PASSWORD="your_wifi_password"'
        '-D DEFAULT_ACCESS_KEY="your_default_access_key"'
        '-D INFLUXDB_TOKEN="your_influxdb_token"'
    ```

### 🔌 Прошивка модуля 🔌

1. Подключите микроконтроллер к компьютеру через USB.
2. В Visual Studio Code откройте терминал PlatformIO и выполните команду для прошивки:
   ```sh
   pio run --target upload
   ```
3. Дождитесь завершения процесса прошивки.

### 🌐 Обновление прошивки через OTA 🌐

1. Подключите устройство к Wi-Fi сети.
2. Откройте веб-браузер и перейдите по адресу устройства.
3. В разделе "OTA Update" загрузите новую прошивку и нажмите "Update".

## 📖 Руководство по эксплуатации 📖

### 🔄 Режимы работы 🔄

Прошивка поддерживает два режима работы:
- **POWERSAVE**: режим энергосбережения.
- **FULL**: полный режим работы.

### 📺 Экраны 📺

OLED дисплей отображает следующую информацию:
- **MAIN**: основной экран с информацией о заряде аккумулятора.
- **WIFI**: информация о подключении к Wi-Fi.
- **POWER_CHART**: график мощности.
- **VOLTAGE_CHART**: график напряжения.

### ⚙️ Параметры ⚙️

Основные параметры, которые можно настроить:
- `battery_id`: идентификатор аккумулятора.
- `wifi_ssid`: SSID Wi-Fi сети.
- `wifi_password`: пароль Wi-Fi сети.
- `shunt_mult_res`: коэффициент умножения шунта.
- `sensor_delay`: задержка между измерениями датчика.
- `usb_delay`: задержка между операциями USB.
- `wireless_delay`: задержка между операциями беспроводного интерфейса.
- `display_time`: время отображения информации на дисплее.
- `mode`: режим работы (POWERSAVE или FULL).

### 🔘 Управление кнопкой 🔘

- **Переход между экранами**: однократное нажатие кнопки осуществляет переход между экранами(MAIN/WIFI/POWER_CHART/VOLTAGE_CHART).
- **Переключение режимов**: удержание кнопки в течение 5 секунд переключает режим работы (POWERSAVE/FULL).
- **Сброс**: три последовательных нажатия и удержание кнопки в течение 5 секунд сбрасывает настройки и перезагружает устройство.

### 🔌 Использование USB интерфейса 🔌

Для взаимодействия с устройством через USB используйте последовательный монитор. Основные команды:
- `1`: Настройки
- `2`: Вывести информацию о системе
- `3`: Самопроверка                       - проверка инициализации подключённых компонентов
- `4`: Результаты самопроверки
- `5`: Рестарт
- `6`: Сброс (очистка памяти + рестарт)   - возвращает настройки, выставленные в прошивке
- `7`: Вычисление коэффициента            - коррекционный множитель для сопротивления шунта

### 📡 Использование беспроводного интерфейса 📡

Устройство поддерживает взаимодействие через Wi-Fi. Основные эндпоинты:
- `/ping`: проверка доступности устройства.
- `/data`: получение данных метрик.
- `/settings`: получение настроек.
- `/selfcheck`: получение результатов самопроверки.
- `/restart`: перезагрузка устройства.

#### Примеры запросов

- **Пример проверки доступности устройства**:
    ```http
    GET /ping HTTP/1.1
    Host: {{HOST}}:{{PORT}}
    api_key: ••••••
    ```
- **Пример обновления настроек**:
    ```http
    POST /settings HTTP/1.1
    Host: {{HOST}}:{{PORT}}
    Content-Type: application/json
    api_key: ••••••
    Content-Length: 75

    {
        "wifi_ssid": "your_wifi_ssid",
        "wifi_password": "your_wifi_password!"
    }
    ```
